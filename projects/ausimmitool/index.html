Australian Skilled-Migration Toolbox

ausimmitool.com · solo, end-to-end

Skilled-migration data in Australia is published monthly in a government dashboard that is hard to query. I built a public site that turns it into something people can use: per-occupation dashboards, a treemap heatmap of the whole EOI pool, and a watchlist that follows the occupations a visitor cares about.

The pipeline scrapes the SkillSelect dashboard (a Qlik engine over WebSocket), detects each monthly release and rebuilds the site through GitHub Actions. A Cloudflare Worker serves an LLM-based CV-to-occupation matcher and email login for synced watchlists.

Highlights

  • Automated monthly data collection, cleaning and site rebuild
  • Interactive treemap heatmap and occupation dashboards
  • LLM CV-to-occupation matching behind a Cloudflare Worker API
  • Written for a non-technical audience
